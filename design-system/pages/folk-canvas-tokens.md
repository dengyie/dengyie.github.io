# Folk Canvas Tokens

## Purpose

Create a semantic token layer for the Folk Canvas direction before page implementation. Tokens should be reusable from CSS Modules through `var()`.

## Token Scope

- Dark-first color system with charcoal backgrounds, parchment text, Dala red, ochre, and deep teal.
- Playfair Display display stack and Inter body stack.
- 4px spacing scale.
- Hand-drawn asymmetric radii for bento cards and crafted buttons.
- Warm red/ochre glow shadows.
- CSS-native decorative diamond and weave patterns for rails, dividers, and borders.
- Shared transition timing for hover and press micro-interactions.
