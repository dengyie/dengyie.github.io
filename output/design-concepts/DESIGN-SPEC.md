# Folklore & Code Homepage Concept Set

## Shared Requirements

- 1440 x 900 concept board with one desktop homepage and one 390 x 844 mobile frame.
- Dark-first editorial publication with realistic blog content.
- Primary navigation, hero/featured post, recent-post bento grid, category cloud, and footer.
- Clear AA-oriented contrast, readable hierarchy, and mobile content prioritization.

## Concept A - Folk Canvas

- Mood: hand-painted, warm, crafted, expressive.
- Palette: charcoal, Dala red, ochre, parchment, deep teal.
- Composition: organic bento blocks with ornamental rails and patterned dividers.
- Typography: expressive serif display with grounded sans-serif metadata.

## Concept B - Editorial Bold

- Mood: decisive, minimal, typographic, high-fashion editorial.
- Palette: near-black, paper white, signal red.
- Composition: oversized asymmetrical headline and strict editorial grid.
- Typography: huge serif headline, neutral sans-serif body, compact uppercase labels.

## Concept C - Neo-Bento Lab

- Mood: luminous, technical, experimental, future-facing.
- Palette: black glass, ultraviolet, cyan, acid lime.
- Composition: dense modular glass bento with glowing data-like borders.
- Typography: wide geometric sans-serif with monospaced labels.

## Concept D - Warm Darkroom

- Mood: photographic, intimate, grainy, archival.
- Palette: dark brown-black, amber, muted red, silver-gray.
- Composition: developed-print cards pinned into a carved wooden editorial frame.
- Typography: cinematic serif display with restrained sans-serif metadata.
